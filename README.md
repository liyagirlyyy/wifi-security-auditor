# 🔐 Wi-Fi Password Security Auditor

A web-based cybersecurity project that audits the security of a Wi-Fi configuration.

## Features

- Wi-Fi password strength analysis
- Password length checking
- Uppercase/lowercase detection
- Number and special-character detection
- Common weak-password detection
- SSID/password similarity check
- WPA/WPA2/WPA3 security evaluation
- WPS status evaluation
- Overall security score from 0–100
- Security recommendations
- Fully client-side operation

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter your Wi-Fi SSID.
4. Enter the Wi-Fi password.
5. Select the Wi-Fi security mode.
6. Select the WPS status.
7. Click **Audit Wi-Fi Security**.

## Security & Privacy

The application performs the audit locally in the browser.

The password is not sent to a server by this application.

This project does not attempt to crack passwords, access Wi-Fi networks, capture wireless traffic, or test credentials against routers.

## Project Purpose

This project demonstrates basic cybersecurity concepts including:

- Password security
- Wireless security configuration
- Security scoring
- Client-side validation
- Security recommendations
